PLANK Host

Secure remote access to this Mac from PLANK Client.

  • Requires an Apple Silicon Mac running macOS 27 or later, with FileVault disabled for access after reboot.
  • Installs PLANK Host in Applications and configures automatic startup at the login screen and on the desktop.
  • Disconnect existing remote sessions before continuing. Upgrades preserve your configuration, certificates and logs.
  • A restart is recommended after installation to finish loading the microphone driver. You can restart later.
  • macOS privacy approvals are still required. Development builds upgrading to this Developer ID-signed app may require approval again.

No Terminal commands, Python installation or developer tools are required.
