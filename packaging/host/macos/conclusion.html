PLANK Host is installed

Open PLANK Host in Applications to review and grant macOS privacy permissions.

Screen recording, Accessibility and input permissions are managed in System Settings → Privacy & Security. Audio consent is requested when desktop audio capture starts.

Restart this Mac to finish setup. Restarting loads the PLANK audio devices and completes any pending camera extension updates.

Save your work before restarting. Remote sessions and applications on this Mac will close. You can restart later, but audio device changes may not take effect until then.

Startup is configured for the login screen and desktop.

To uninstall, run the included script in Terminal:

sudo "/Applications/PLANK Host.app/Contents/Resources/uninstall.sh"

Uninstall automatically requests PLANK Camera removal. If enabled, approve any macOS prompt on the Mac desktop. If macOS requires a restart, restart when ready and run the same command again; the Host app is kept until camera removal is verified. Restart after uninstall to unload the PLANK Output and Microphone audio devices.

Configuration, certificates, logs and privacy permissions are retained. No separate download is needed.
