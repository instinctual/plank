# PLANK 1.2.05

Changes since [1.1.039](https://github.com/instinctual/plank/releases/tag/v1.1.039),
the previous published release. Release preparation is in progress; package
builds and installed acceptance are recorded separately in HANDOFF.

## Client

- Ubuntu now uses Qt streaming windows and direct PipeWire audio playback under the ordinary PLANK Client name. Existing bookmarks, settings and trusted Hosts are retained.
- Run separate fullscreen sessions on separate monitors, or span one session across both. Select the displays per bookmark or switch fullscreen presentation from the toolbar.
- New bookmarks default to Native (1:1 pixels). Existing scaling preferences are preserved.
- Improve toolbar access in windowed sessions, restore clear icons, and remember a sensible window size when leaving fullscreen.
- Recover automatically after temporary network interruptions, with Disconnect available while waiting.
- Fix mouse-wheel scrolling in Linux desktop applications and false “Waiting for Workstation” warnings on idle desktops.
- Improve Wacom USB recovery while preserving a healthy matching virtual tablet on the Host.
- Improve Ubuntu audio timing and recovery from short playback shortages. Hardware audio/video synchronization still requires real-session observation.

## Host

- Improve first-click application switching on macOS by keeping mouse press, drag and release events paired.
- Provide one Apple Silicon Host package for macOS 26.7 and newer, built with SDK27 and retaining newer macOS capabilities.
- Build the Linux Host with CUDA 13.2 Update 2 for the qualified NVIDIA driver baseline, preserving existing codec profiles and GPU architecture support.

## Packages and validation

- Linux Host: Rocky Linux 9.7, x86-64 RPM.
- Linux Client: Ubuntu 26.04, x86-64 DEB.
- macOS Host: macOS 26.7 or newer, Apple Silicon PKG.
- macOS Client: macOS 15 or newer, Apple Silicon PKG.

Both Mac packages require Developer ID signing, notarization, stapling and
Gatekeeper checks. `SHA256SUMS` and `manifest.json` retain package hashes,
exact source revisions and build-validation status. Passing hosted tests does
not imply installed session acceptance. Chris (cnoellert) owns macOS26.7 Host
testing; the identical Host installer also needs macOS27 validation.

Unfinished native Apple Client work is outside this release. The deferred Intel
VA-API surface-timeout investigation is not claimed fixed. No machine is
automatically upgraded by publishing the packages.
