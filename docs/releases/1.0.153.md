# PLANK 1.0.153 candidate

## Client

- Remember the Host identity before sending credentials, independently of bookmarks.
- Offer Cancel or Trust Replacement Host when that identity changes.
- Stop automatic reconnect rather than silently trusting a replacement machine.

## Host

- macOS: give login-screen and desktop workers a common machine identity while
  keeping their private keys separate.
- Renew certificates without replacing the machine key.

This `code-review-fixes` candidate retains the pending 1.0.152 display changes.
It is not merged or released. First connection uses automatic trust on first
use, not independent verification of Host identity. See
`docs/security/host-identity-trust.md` for limitations and acceptance gates.
