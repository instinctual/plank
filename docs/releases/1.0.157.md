# 1.0.157 candidate

## Host

- macOS: tolerate slow certificate preparation during the first desktop login
  after reboot without the former one-second helper timeout.
- Keep issuance, reply and abandoned-connection waits bounded and aligned.
  Certificate verification and desktop ownership checks remain mandatory.

This candidate retains the accepted microphone integration. The fix changes
only macOS Host startup; Client runtime, Linux Host and transport are unchanged.
Clients from the matching 1.0.156 microphone candidate do not need an update.

Native tests cover slow successful helpers, cumulative deadline exhaustion,
child termination/reaping, real certificate signatures, delayed XPC replies
and scope changes during issuance. Post-reboot login acceptance remains a
separate live test; synthetic tests do not prove the complete desktop handoff.
