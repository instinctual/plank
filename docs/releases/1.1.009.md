# 1.1.009 Remote output routing

During desktop sessions, the macOS Host captures only audio sent to PLANK Output.
Built-in speakers and other physical outputs retain normal local playback, including applications
that select those outputs directly. Remote volume and mute follow PLANK Output's
controls even when another device is selected for local playback.

Fix automatic PLANK Output selection by creating a private routing-recovery
directory during installation. Earlier builds attempted to store the private
journal in the shared settings folder and rejected that folder's permissions.
The shared folder remains readable; the recovery journal remains private.

The Host selects PLANK Output after remote audio starts and restores prior
devices at disconnect unless the user changes them. If automatic selection
fails, PLANK Output can still be selected manually. Missing output drivers no
longer cause capture to fall back to physical outputs.

Existing compatible Clients, including Ubuntu Client1.1.006, use the same audio
transport. This candidate still requires installed playback/routing validation.
