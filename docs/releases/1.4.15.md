# PLANK 1.4.15

Changes since [1.4.12](https://github.com/instinctual/plank/releases/tag/v1.4.12).

## Host

- Fix the macOS Host appearing offline because optional metrics settings prevented startup, including when metrics were disabled.
- Reuse Native X11 capture buffers to reduce repeated allocation and GPU-registration stalls.
- Add capture-buffer timing to Linux Host logs for performance diagnosis.

## Client

- Include these release notes in the version dialog. Client runtime behavior is unchanged.

## Configuration

Metrics remain disabled by default on macOS Host and Client. The Host startup
correction preserves existing administrator settings and workstation identity;
no configuration workaround is needed.

## Build support

- Reuse verified Linux Host compiler outputs while keeping fresh linking, tests and full CUDA architecture coverage.
- Add a focused Native10 test workflow for faster capture experiments.
- Test the complete macOS configuration-to-startup path so optional settings cannot silently prevent Host startup.

## Known limitation

The previously observed Native X11 tearing remains unresolved. The diagnostic
experiments were retired without changing production capture behavior.

## Packages

| Package | Platform |
| --- | --- |
| Linux Host RPM | Rocky Linux 9.7, x86-64 |
| Linux Client DEB | Ubuntu 26.04, x86-64 |
| macOS Host PKG | macOS 26.7 or newer, Apple Silicon |
| macOS Client PKG | macOS 15 or newer, Apple Silicon |

The separate native Apple/Vision clients are outside this release.

## Validation

The signed macOS Host candidate passed the new configuration/startup regression
tests. After installation on the authorized development Mac, its sign-in worker
and control listener started successfully with metrics disabled. Configuration
and workstation identity remained unchanged. This verifies startup; a new
interactive desktop session has not yet been recorded for this correction.

All four mainline packages were built on GitHub from
`529f4ce2fffc9fdef2f9f09ec981844a742149d3`; every build passed on its first attempt.
Both Mac PKGs are signed, notarized, stapled and Gatekeeper-accepted. Original
builder manifests, downloaded package checksums and source pins are verified.
Privacy and clipboard regressions also passed.

The Linux transport passed three 900-frame tests at 150 Mbps, with zero
unrecovered data and zero proxy kernel drops. Hosted Mac functional checks and
the new startup regression passed. Transport code is unchanged from 1.4.12;
its existing hardware qualification is retained separately. No new mainline
package installation or Mac performance soak was performed.

Installers, the manifest and checksums are in
`artifacts/packages/releases/1.4.15/`. Building packages does not publish a
GitHub release.
