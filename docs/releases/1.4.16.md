# PLANK 1.4.16

Changes since [1.4.15](https://github.com/instinctual/plank/releases/tag/v1.4.15).

## Host

- Fix the macOS Host appearing offline after another installer makes the shared Application Support folder writable by administrators.
- Apply the same correction to Host installation and removal.
- Report the specific directory when unsafe permissions prevent startup or installation.

The fix accepts only the expected root-owned, administrator-group permission
on the shared system folder. PLANK's own directories, configuration and private
keys retain their protection. Existing settings and workstation identity are
preserved, and the installer does not change the shared folder's permissions.

## Client

- Include these release notes in the version dialog. Client runtime behavior is unchanged.

Linux Host runtime behavior is unchanged. Metrics remain disabled by default
on macOS Host and Client.

## Packages

| Package | Platform |

The separate native Apple/Vision clients are outside this release.

## Validation

The signed macOS Host candidate passed the directory-permission, configuration,
startup and installer regression tests. On the affected macOS 27.2 machine,
installation restored the running desktop worker and network control endpoint
while preserving configuration, identity, keys and the shared folder's mode.
No reboot or logout was performed. This is installed startup validation;
new interactive-session and macOS 26.7 acceptance were not recorded for this fix.

All four mainline packages were built on GitHub from
`a90bf46edcc3817719ffa3b13fc5cb0238032a34` and passed their package gates.
Both Mac installers are signed, notarized, stapled and Gatekeeper-accepted.
Downloaded archives, original manifests and package checksums are verified.
Privacy, clipboard and Client compositor/input/launcher checks passed. Linux
transport passed three 900-frame tests at 150 Mbps with zero unrecovered data
and zero proxy kernel drops.

One unchanged transport round-trip test timed out in the initial unsigned Mac
Host job. It passed in the independent signed Host build and in a targeted retry
of the failed job, with identical source and limits. The cause of that single
timeout is not established; its evidence is retained. No test was weakened.
Transport code is unchanged from the preceding release, and no new Mac
performance soak or mainline-package installation was performed.

## Known limitation

The previously documented Native X11 tearing remains unresolved.

The four installers, source manifest and checksums are published in
[PLANK 1.4.16](https://github.com/instinctual/plank/releases/tag/v1.4.16).
All six uploaded asset sizes and digests match the verified local files.
The original package catalog remains in `artifacts/packages/releases/1.4.16/`.
