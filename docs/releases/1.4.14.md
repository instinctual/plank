# PLANK 1.4.14

Changes since [1.4.12](https://github.com/instinctual/plank/releases/tag/v1.4.12).

## Host

- Reuse Native X11 capture buffers to reduce repeated allocation and GPU-registration stalls.
- Add capture-buffer timing to Linux Host logs for performance diagnosis.

## Build support

- Reuse verified Linux Host compiler outputs while keeping fresh linking, tests and full CUDA architecture coverage.
- Add a focused Native10 test workflow for faster capture experiments.

## Known limitation

The previously observed Native X11 tearing remains unresolved. The diagnostic
experiments were retired without changing production capture behavior.

## Packages

| Package | Platform |
| --- | --- |
| Linux Host RPM | Rocky Linux 9.7, x86-64 |
| Linux Client DEB | Ubuntu 26.04, x86-64 |
| macOS Host PKG | macOS 26.7 or newer, Apple Silicon |
| macOS Client PKG | macOS 15 or newer, Apple Silicon |

The Client bundles the updated release notes. The separate native Apple/Vision
clients are outside this release.

## Build verification

All four packages were built on GitHub from
`0c197608ff6498663e8b9631732adfa13d53e2c8`; every workflow passed on its first
attempt. Both Mac PKGs are signed, notarized, stapled and Gatekeeper-accepted.
The downloaded package checksums and source manifests are verified.

The Linux transport passed three 900-frame tests at 150 Mbps, with zero
unrecovered frames and zero proxy kernel drops. Hosted Mac functional checks
also passed. Transport code is unchanged from 1.4.12; its existing hardware
qualification remains recorded separately. These packages have not been installed
for new hardware/session acceptance.

The prepared installers, manifest and checksums are in the local
`artifacts/packages/releases/1.4.14/` catalog. GitHub release publication is a
separate step.
