# 1.1.007 Mac remote audio output

The macOS Host adds **PLANK Output**, a 48 kHz stereo playback destination with
volume and mute controls. Once remote desktop audio starts, PLANK selects it
for playback and system alerts. Remote volume starts from the previous output's
level; later adjustments leave the physical device's controls unchanged.

On disconnect, PLANK restores the previous devices if its selections remain
active. Manual device changes take precedence. A private routing journal and
coordinator recovery cover interrupted cleanup; an unplugged original output
falls back to an available built-in output. Applications explicitly configured
for another output remain covered by the existing process-scoped capture path.

The Host continues using its existing Core Audio tap, Opus encoder and Kymux
connection. No Client upgrade or new media protocol is required for this Host
feature. The virtual output has no public loopback input or physical playback.

Installer recommends restarting to load the PLANK audio devices and complete
pending extension updates. Save work before restarting; the recommendation can
be deferred. Live device, volume, routing and failure-recovery qualification
remain required for this candidate.
