# 1.1.004 media compatibility candidate

Mac Host and Client now negotiate desktop, output audio, input, clipboard,
microphone and camera contracts separately. Optional features can be disabled
while desktop connectivity remains available. Incompatible required features
produce an explicit connection error without changing the selected video profile.

The new Host accepts launch schemas4/5/6 from existing Clients. Schema4 retains
desktop, sound output and input, with reverse microphone forwarding disabled
because its mono packet format differs. Schema5 retains stereo microphone;
camera requires schema6 or the new feature envelope. A new Client can also
connect to known older Hosts from1.0.156 through1.1.003 using explicit adapters.
Earlier transports are unsupported; Linux Host negotiation is unchanged.
See [the compatibility contract](../../protocol/media-feature-negotiation.md).

This candidate includes the native camera and stereo audio improvements in
[1.1.003](1.1.003.md). Camera capture remains off until enabled in the toolbar,
including after reconnect. The Mac camera extension needs normal OS approval.
Signing, installation, sustained media testing and real application acceptance
must be recorded separately; this document does not assert those gates passed.
