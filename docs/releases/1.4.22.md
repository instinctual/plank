# PLANK 1.4.22

This release adds Tangent Element panel forwarding from Ubuntu to Rocky Linux and increases network receive headroom on Linux and macOS. It includes the changes since [PLANK 1.4.18](https://github.com/instinctual/plank/releases/tag/v1.4.18).

## Client

- Connect an Element Tk, Mf, Kb or Bt, or the KnobX1 Mf emulator, to the Ubuntu Client. The first authenticated PLANK session that claims the panels keeps them until disconnect, including when another session window has focus.
- Busy panels retry automatically. USB requests and cancellations are tracked per panel so another panel can keep working during a disconnect.
- The Client requests a 4 MiB QUIC receive buffer to absorb short packet bursts. Its log records the size the operating system grants.

## Host

- TangentHub sees each forwarded panel as a separate USB device on the Rocky Linux Host. The Host RPM includes the virtual USB driver and its corresponding source. Panel traffic uses the existing authenticated PLANK connection.
- The Host requests the same 4 MiB receive buffer and logs the grant. Both Linux packages include an editable `/etc/sysctl.d/10-plank-receive-buffer.conf` for the receive-buffer ceiling. A higher administrator setting is preserved.

## Installers

| Product | Platform |
| --- | --- |
| Host RPM | Rocky Linux 9.7, x86-64 |
| Client DEB | Ubuntu 26.04, x86-64 |
| Host PKG | macOS 26.7 or newer, Apple Silicon |
| Client PKG | macOS 15 or newer, Apple Silicon |

For the full Element series, upgrade both the Rocky Host and Ubuntu Client. The macOS packages include the network changes.

## Hardware validation

All four genuine panels' USB and HID descriptors were verified. TangentHub opened the forwarded KnobX1 during a PLANK session, and a genuine Mf enumerated on the Host. The KnobX1 jog, Play/Stop and four modes worked in Flare through the initial compatibility probe. Hands-on testing of every genuine panel's controls and display feedback, simultaneous use, unplugging and takeover is still pending.
