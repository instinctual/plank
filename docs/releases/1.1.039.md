# PLANK 1.1.039

Changes since [1.1.030](https://github.com/instinctual/plank/releases/tag/v1.1.030),
the previous published release. Update Host and Client together to receive the
complete input-recovery improvements.

## Client

- Improve Wacom recovery after reconnects, focus changes and temporary network stalls.
- Keep tablet control requests from blocking pen input, and update the Wayland tablet cursor independently of video playback.
- Fix Linux Wayland tablet-cursor cleanup and protect session shutdown from late input callbacks.
- Improve downscaling in Mac windows so fine lines and small details are preserved. Use the active display's pixel geometry when choosing the initial stream size.
- Keep the original stream resolution when switching between fullscreen and windowed mode.
- Distribute the Mac Client directly as a signed PKG, without the extra DMG wrapper.

## Host

- Linux: preserve a healthy, matching virtual Wacom tablet across disconnects, reconnects and session takeover, instead of unnecessarily recreating it.
- Linux: release held keys, buttons and pen contact before handing control to a replacement session; verify tablet cleanup and recover unhealthy devices.
- Linux: prevent Xorg from recalibrating pressure a second time for forwarded tablets.
- Linux: improve NvFBC/NVENC downscaling on the GPU while preserving the selected color precision and RGB identity mapping.

## Shared

- Handle short bursts of reliable input without immediately ending the connection when its queue is full.
- Add opt-in transport support and tests for hardware-encoded Mac camera records. This is groundwork, not a new end-to-end camera feature.

## Validation and remaining checks

The four packages were built from main commit
`2b3279755bd7ed27ffcd380a0121e9793bf469e6` and passed hosted compilation,
automated regression tests and package checks:
[Linux Host](https://github.com/instinctual/plank/actions/runs/38287535913),
[Ubuntu Client](https://github.com/instinctual/plank/actions/runs/38286682059/job/114936731007),
[macOS Host](https://github.com/instinctual/plank/actions/runs/38287229443), and
[macOS Client](https://github.com/instinctual/plank/actions/runs/38287233183).
Both Mac PKGs are signed, notarized and stapled.

The Linux Host passed three 900-frame loss-matrix runs with zero unrecovered
source symbols, plus repeated input-lifecycle tests. Three real-kernel tablet
cases were unavailable on the builder; all wrapped-UHID fixture cases passed.
These tests do not replace real hardware or WAN qualification.

Live acceptance of the new persistent-tablet behavior in Flame, including
network interruption, pressure and Tablet Margins, remains pending. Long
audio/video synchronization soaks and qualification of the identical Mac Client
on both macOS 15 and 27 remain separate gates. Previously deferred Wallpaper/
Screen Saver pointer lag and Linux physical-display provenance issues are not
claimed fixed. No machines were automatically upgraded for this publication.

## Packages

- Linux Host: Rocky Linux 9.7, x86-64 RPM.
- Linux Client: Ubuntu 26.04, x86-64 DEB.
- macOS Host: macOS 27 or newer, Apple Silicon PKG.
- macOS Client: macOS 15 or newer, Apple Silicon PKG.

`SHA256SUMS` uses the downloadable package filenames. `manifest.json` records
exact source revisions, dependency pins and package-validation status separately
from live functional acceptance. The packages are unchanged from the verified
1.1.039 mainline build.

GitHub source archives omit submodules. To obtain the complete source:

```sh
git clone --recurse-submodules --branch v1.1.039 https://github.com/instinctual/plank.git
```
