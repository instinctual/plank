# 1.1.008 Camera setup status

The macOS Host setup window recognizes an already-enabled PLANK Camera and
shows its enabled status without offering another Enable Camera button. It
also updates an enabled camera extension through macOS's normal replacement
flow, preserving the existing approval when macOS allows it.

First-time and disabled cameras still require an explicit setup action.
Genuine approval requests, setup failures and restart requirements remain
visible. Camera capture still starts only from the Client toolbar.

This is a Host-only change. Existing compatible Clients can remain installed.
