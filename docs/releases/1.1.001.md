# 1.1.001 — next version (not published)

Update Host and Client together. RaptorQ 2.0.1 changes recovery data on the
wire; native transport negotiation rejects older incompatible peers rather
than attempting to decode mixed-version data. The new macOS microphone setup
also requires a matching Client. Do not pair this line with the previous
published release.

## Client

- Microphone forwarding to macOS Hosts, automatic/manual controls and toolbar mute.
- Automatic first-use Host identity storage and explicit replacement confirmation.
- Safer malformed-data handling, connection cancellation and rendering shutdown.
- More reliable audio/video startup and queue handling.

## Host

- RaptorQ 2.0.1 recovery and removal of the application datagram pacer.
- macOS virtual microphone input with automatic selection/restoration.
- More tolerant, bounded certificate preparation during first login after reboot.
- Bounded Linux PAM authentication and incoming-data validation.

This version number starts the 1.1.xxx line at the operator's request. It does
not publish a release, retag a commit or rename any existing 1.0.x candidate.
The signed 1.0.157 microphone-branch Host remains the pre-merge test artifact;
new mainline packages must be rebuilt from their exact 1.1.001 source.
