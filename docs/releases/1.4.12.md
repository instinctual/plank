# PLANK 1.4.12

Changes since [1.2.05](https://github.com/instinctual/plank/releases/tag/v1.2.05),
the previous published release.

## Client

- Bring the shared Qt toolbar, display controls and connection recovery to macOS, with Metal presentation and native Core Audio. Desktop Clients no longer require SDL.
- Save multiple bookmarks for the same Host, each with its own name and settings.
- Show Internet connectivity separately from Host availability, with live ping details when clicked. Background checks pause when the main window is hidden.
- Improve video recovery, decoder backpressure and session shutdown. HEVC requires an exact-format hardware decoder; supported H.264 profiles retain software decoding.
- Hide Match Host for virtual/headless Hosts and prevent accidental dismissal of bookmark dialogs.
- Add optional session, network, decoding and rendering metrics for Telegraf/Grafana. Ubuntu sessions can also report Wacom movement and tip-contact counts without recording coordinates, strokes or pressure values.

## Host

- Start sending Linux video before its FEC repair data is ready, sharing the same approach as macOS. Give short video bursts more queue headroom and improve recovery from temporary congestion.
- Reduce copying and overhead in Linux capture and encoding while preserving the supported 8-bit/10-bit 4:4:4 RGB identity workflows.
- Improve macOS login handoff after a reboot and mouse dragging in QuickTime's screen-recording selection.
- Add optional physical-display mirroring on macOS and improve virtual-display readiness and cleanup during takeover/shutdown.
- Release held mouse buttons and keys reliably after disconnects, bound incoming requests, and improve Linux audio cancellation and recovery.
- Add optional Host transport, bitrate and processing metrics for a local Telegraf agent.

Metrics are disabled by default. Enable them in the administrator configuration
and configure a local Telegraf agent to collect them; PLANK does not install
Telegraf or store InfluxDB credentials. An InfluxQL Grafana dashboard is included
in the repository. Use matching Host and Client versions when deploying this update.

## Packages

| Package | Platform |
| --- | --- |
| Linux Host RPM | Rocky Linux 9.7, x86-64 |
| Linux Client DEB | Ubuntu 26.04, x86-64 |
| macOS Host PKG | macOS 26.7 or newer, Apple Silicon |
| macOS Client PKG | macOS 15 or newer, Apple Silicon |

Both Mac installers are signed, notarized and stapled. All four packages were
built on GitHub from `0cf0923b952685f918ceed53c8f39391de0e0651`.
`SHA256SUMS` uses the downloadable filenames; `manifest.json` records exact
source revisions, package hashes and validation status.

## Validation

All product build/package gates and Linux/macOS transport checks passed. The
Linux Host required one unchanged retry after a loopback assertion saw source
symbols missing before FEC despite complete video recovery; no test or limit was
changed. The Mac transport also passed three 900-frame tests at 150 Mbps on the
authorized development Mac, with zero unrecovered frames. Details are recorded
in the [build handoff](https://github.com/instinctual/plank/blob/51dfc0e9/HANDOFF.md).

Package checks do not establish installed hardware acceptance. Exact-format
hardware decoding, color, Wacom and long audio/video soaks remain hardware checks;
Chris owns macOS 26.7 session qualification. Intel NUC Gen11 remains unqualified.
The separate native Apple/Vision clients are outside this release.

GitHub source archives omit submodules. To obtain the complete source:

```sh
git clone --recurse-submodules --branch v1.4.12 https://github.com/instinctual/plank.git
```
