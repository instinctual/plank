# PLANK 1.1.024

Changes since [1.0.143](https://github.com/instinctual/plank/releases/tag/v1.0.143),
the last published release.

**Upgrade Host and Client together.** The updated network recovery format is
not compatible with 1.0.143.

## Client

- Forward your microphone from Linux or macOS to a Mac Host, with a toolbar mute control. New configurations start muted.
- Forward supported webcams from Ubuntu to a Mac Host. Camera forwarding starts off.
- See when a workstation is **In Session**, with an optional username shown when the Host administrator allows it.
- Optionally remember the last successful username for each bookmark. Passwords are never saved.
- Move your active Mac session to another Client using **Take Over**, including when the Mac is locked.
- Remember each Host's identity and ask before accepting a changed identity.
- Install the macOS Client with a PKG, including permission setup, administrator configuration and an uninstaller.
- Use clearer Mac setup windows and distinct Host and Client icons.
- Improve connection cancellation, shutdown, display discovery and Wacom recovery after switching apps or Spaces.
- Click the version number to read the built-in changelog.

## Host

- macOS: add **PLANK Microphone** and **PLANK Camera** for remote input in applications.
- macOS: route remote sound through **PLANK Output**, with independent volume and mute. Restore previous audio devices after disconnect.
- macOS: improve login-screen transitions, session takeover and recovery after startup or user changes.
- macOS: use documented `/etc/plank/host.conf` settings, including workstation name, connection timeout and optional username publication.
- macOS: simplify permission setup and improve removal of optional devices during uninstall.
- Linux: improve virtual-monitor ordering and release held tablet contact when forwarding pauses, without recreating the tablet.
- Both platforms: upgrade network loss recovery and handle malformed data, connection cancellation and queue overflow more safely.
- Linux: prevent a stalled operating-system login check from blocking other authentication requests indefinitely.

All four packages have passed their automated build checks; both Mac installers
are signed and notarized. Live qualification of the latest Wacom changes remains
pending. This changelog does not publish a GitHub release.
