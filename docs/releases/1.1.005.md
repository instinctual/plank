# 1.1.005 Mac Client display discovery

The Mac Client can start a session when macOS lists no display mode marked
native. It uses the current mode's backing-pixel dimensions in that case,
without switching the display mode. Previously this condition could return
the Client from Starting Desktop to the bookmark list before stream launch.
Actual display-discovery failures now show a connection error.

This Client retains the independent media negotiation introduced in
[1.1.004](1.1.004.md). The existing 1.1.004 Host can remain installed.
The display fix requires a Client update; a Host update cannot repair the
older Client's local display-discovery failure.
